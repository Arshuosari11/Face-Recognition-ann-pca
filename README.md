AI Face Recognition System using PCA + ANN

An AI-based Face Recognition System developed using Principal Component Analysis (PCA) and Artificial Neural Network (ANN).
This project recognizes faces from uploaded images through dimensionality reduction and neural network classification.

Features
Face Recognition using PCA Eigenfaces
ANN-based Classification
Image Upload Support
Streamlit Web Application
GitHub Deployment Ready
Multiple Person Recognition

Technologies Used
Python
OpenCV
NumPy
Scikit-learn
SciPy
Matplotlib
Streamlit

Project Workflow
Load face dataset
Convert images to grayscale
Resize images
Apply PCA for feature extraction
Train ANN model
Predict face identity
Display result on Streamlit app

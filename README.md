# AI Face Recognition System using PCA + ANN

An AI-based Face Recognition System developed using **Principal Component Analysis (PCA)** and **Artificial Neural Network (ANN)**. This project recognizes faces from uploaded images through dimensionality reduction and neural network classification.

---

## Features

- Face Recognition using PCA Eigenfaces
- ANN-based Classification
- Image Upload Support
- Streamlit Web Application
- GitHub Deployment Ready
- Multiple Person Recognition

---

## Technologies Used

- Python
- OpenCV
- NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Streamlit

---

## Project Workflow

1. Load face dataset
2. Convert images to grayscale
3. Resize images
4. Apply PCA for feature extraction
5. Train ANN model
6. Predict face identity
7. Display result on Streamlit app

## Installation

Clone the repository:

```bash
git clone https://github.com/Arshuosari11/Face-Recognition-ann-pca.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
